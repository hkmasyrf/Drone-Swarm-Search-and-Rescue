# Drone-Swarm-Search-and-Rescue
Agent-Based Modeling of Drone Swarm Search and Rescue using NetLogo

## Project Overview
This project uses Agent-Based Modelling (ABM) in NetLogo to simulate multiple drones searching a disaster-affected environment for survivors.

## Objectives
- Simulate multiple autonomous drones searching for survivors.
- Investigate how drone movement and detection radius affect search performance.
- Monitor survivor detection and search coverage during the simulation.

## Model Features
- Multiple drone agents and survivor agents.
- Drone movement and obstacle avoidance.
- Survivor detection using a configurable detection radius.
- Search coverage and mission progress monitoring.
- Visualisation of drone movement trails and detected survivors.

## Software
- NetLogo

## How to Run
1. Open the model file in the compatible NetLogo version.
2. Click Setup to initialise the simulation.
3. Click Go to start the simulation.
4. Observe drone movement, survivor detection and search coverage.
